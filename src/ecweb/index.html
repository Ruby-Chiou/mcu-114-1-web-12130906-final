回作品集 113 學年第 2 學期網頁程式設計期末專案

電商平台

這是大二網頁程式設計的期末專案。用 ASP.NET Core MVC 做一個購物網站，可以註冊、依名稱和價格找商品、加入購物車、結帳，後台也能看營收、改訂單狀態，以及管理商品、類別和廠商。

會員帳號和商品訂單分成兩個 SQL Server 資料庫。網站要接資料庫才能跑，所以這裡放的是當時示範影片的畫面，沒有把整站掛到 GitHub Pages。

前台

找商品

首頁有精選和最新上架。商品列表可以打關鍵字、設價格區間，也可以依類別看。

會員

買東西

註冊後要驗證信箱。登入才能把商品放進購物車。結帳時再檢查庫存，寫入訂單、扣庫存，並清空購物車。

後台

管理

只有 Admin 進得去。控制台統計商品、訂單、營收和熱銷，也可以改訂單狀態、維護分類廠商，以及調整會員角色。

技術是 ASP.NET Core 8、MVC、Identity、Entity Framework Core、SQL Server、Razor 和 Tailwind。畫面截自 2025 年 6 月的期末示範。
